新设备（ESP32）接入，先这样操作：
  1. 用 USB 把 ESP32 连电脑 / 上电（首次会自动开热点 ESP32-Config）。
  2. 用手机连它的 WiFi ESP32-Config，打开浏览器进 192.168.4.1，填 WiFi 名称/密码 + 服务器地址，保存。
  3. 设备联网后，本页“设备管理”会出现它，并提示“已注册成功”。
  4. 在下方把它绑定座位、选传感器类型（HC-SR501/红外）、设上报间隔，保存即可——之后改这些都不用再烧固件。

下方每个座位都能：① 开关“是否接收传感器上报”；② 用按钮手动模拟上报（等价于 ESP32 上报，无需真机也能测占用/释放）。

产线烧录配置（批量部署用）

在这里填好 WiFi 和服务器地址，下载生成的 secrets.h 放进 DEMO/src/ 再编译 —— 烧出来的固件已带配置，设备上电直接连 WiFi 注册， 不需要像上面那样一台台开热点手填。适合全校 / 整层楼统一 WiFi 的场景。

⚠️ 两点必读
① WiFi 密码是明文存在服务器上的（data/system_config.json，该文件不对外提供下载）。 这个系统要是会暴露到校外网络，建议这里只填 WiFi 名称，密码在本地手工填进 secrets.h。
② 烧进去的 WiFi 只对那一个网络有效。换 WiFi、换密码、或者一层楼一个 AP 的场景， 仍然需要现场配网（手机连 ESP32-Config 热点，或后续的蓝牙配网）。
