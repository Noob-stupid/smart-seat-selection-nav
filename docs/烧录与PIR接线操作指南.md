# ESP32 烧录 + HC-SR501(PIR) 接线 —— 操作指南

> 你的 PlatformIO 环境已经配好（平台/工具链/框架都装好了，固件能编译）。这份只讲**怎么烧录**和**怎么接 PIR**，照着做即可。环境目录：`D:\MAX_xiangmu\DEMO`。

---

## 一、需要的东西
- 1 块 **ESP32 开发板**（如 ESP32 DevKit，USB 供电）
- **HC-SR501（PIR 人体感应模块）**，推荐 2 个；只用 1 个也可以（见接线）
- 杜邦线若干
- 1 根 USB 数据线（连电脑烧录 + 供电）
- 电脑（已装好 PlatformIO 环境）

> 顺带：你主系统（`app.py`）要能跑，真机上报才有地方去。测试前先把主系统启动（`python app.py 0.0.0.0 5800`，防火墙放行）。

---

## 二、接 HC-SR501（PIR）—— 按这张表插

| HC-SR501 引脚 | 连到 ESP32 | 说明 |
|---|---|---|
| `VCC` | **5V**（若无 5V 引脚可接 3.3V） | HC-SR501 工作电压较高，5V 更稳 |
| `OUT`（信号，第 1 个） | **`GPIO23`**（→ 固件 `ir_front`） | 检测到人体移动时输出 **HIGH** |
| `OUT`（信号，第 2 个） | **`GPIO27`**（→ 固件 `ir_back`） | 第二个传感器接这个 |
| `GND` | **`GND`** | 两个传感器共地 |

- **只用 1 个 HC-SR501**：把唯一的 `OUT` **同时接到 `GPIO23` 和 `GPIO27`**，这样 `ir_front` 与 `ir_back` 永远一致，一个传感器也能触发占用。
- 两个传感器**交叉放置**（一个朝座椅前侧、一个朝后侧，各约 45°），人坐下/起身有动作 → 上报 `(1,1)` → 占用。
- ⚠️ **HC-SR501 是 PIR（人体感应）**：它检测的是“**人体移动**”，**不是静止占座**。人一直坐着不动，它会掉回 LOW、座位可能短暂显示空闲。建议把 HC-SR501 的**延时电位器调到最小**、跳线选 **H（可重复）**、灵敏度调到覆盖座位，并远离热源/空调/窗（见常见问题）。
- 接好给 ESP32 上电，板载 LED 亮/闪即正常。

## 三、烧录固件（把 `firmware.bin` 写进 ESP32）

1. **用 USB 数据线把 ESP32 连电脑** → 打开**设备管理器**，看“端口(COM 和 LPT)”有没有一个 COM 口（如 `COM3`）。
   - 没有 COM 口 → 装这个板子的 USB 芯片驱动：常见 **CP210x**（Silicon Labs）或 **CH340**，装完插拔即可。
   - 记下端口号（如 `COM3`）。

2. **打开终端，进入项目并烧录**：
   ```powershell
   cd D:\MAX_xiangmu\DEMO
   python -m platformio run -t upload
   ```
   - 第一次会自动编译 + 烧录；看到 `Creating esp32 image...` → `Writing...` → `Hard resetting via RTS pin...` 即烧录完成。
   - 如果报**找不到端口**：在 `DEMO\platformio.ini`（`[env:esp32dev]` 下）加一行 `upload_port = COM3`（换成你的实际口），再跑一次。
   - 如果卡在 `Connecting.......`：**在上传刚开始时按住板上的 `BOOT` 键**，出现 `Connecting` 再松开。

3. **（可选）看串口**（固件运行日志）：
   ```powershell
   python -m platformio device monitor   # 波特率 115200
   ```

> 💡 环境已就绪，**不用再下载任何东西**；烧录只用几分钟。

## 四、首次上电配置（烧录后必经，一次）

1. 烧录完，ESP32 会**自动开机**。首次它没配置网络，会开一个热点 **`ESP32-Config`**。
2. 用**手机**连它的 WiFi `ESP32-Config`（无密码）。
3. 手机浏览器打开 **`192.168.4.1`**，填三样：
   - **WiFi 名称 / 密码**（你路由器的）
   - **服务器地址**：`http://<运行主系统电脑的局域网IP>:5800`（电脑上 `ipconfig` 看 IPv4）
4. 点“保存并连接”。设备会保存并自动连接 → **注册到主系统**（用 WiFi MAC 当设备号）。

---

## 五、在管理面板绑定座位（也要做）

1. 浏览器打开 **`http://<主系统IP>:5800`** → 管理员登录 → 进 **`/admin/hardware`**。
2. 你会看到提示“🆕 新 ESP32 已注册成功”，且“设备管理”里出现这台设备（显示在线）。
3. 在「设备管理」给这台设备：
   - **绑定座位**（选你在主系统建的那个座位标签）
   - **传感器类型** = **HC-SR501(高电平)**
   - 上报间隔（默认 5000ms，可不动）
4. 点“保存”。设备拉取配置后就会用它绑定座位、按 PIR 上报。

## 六、真机测试

1. 用另一台设备（手机/电脑）打开用户端 **`/seat-map`**。
2. **人坐到传感器附近/起身** → 座位 ≤5 秒变**红**（占用）。
3. 人离开（传感器检测不到动作）→ 连续两次“无人”上报 → 约 10 秒变**绿**（释放）。

## 七、常见问题

| 现象 | 排查 |
|---|---|
| 烧录报“找不到端口/COM” | 没插好 / 驱动没装（CP210x 或 CH340）；在 `platformio.ini` 加 `upload_port = COMx` |
| 烧录卡 `Connecting...` | 上传瞬间按住板子 `BOOT` 键再松开 |
| 串口没有 `[WiFi] 已连接` | WiFi 名称/密码错，或 ESP32 和电脑不在同一 WiFi |
| 连上 WiFi 但 `HTTP -1` | `192.168.4.1` 里服务器地址填错；主系统没 `0.0.0.0` 启动；防火墙没放行 5800 |
| 面板没看到“注册成功” | 检查设备热点配置时服务器地址对不对；或 `/admin/hardware` 页面刷新 |
| 人坐下座位不变红 | 传感器类型有没有选 **HC-SR501(高电平)**；接线对不对；串口看 `ir=(1,1)` 是否出现 |
| `ir` 一直 0，手晃动没反应 | HC-SR501 的 VCC 没接 5V / OUT 没接对 / 没上电 |
| 人坐下一会儿又变绿 | PIR 只认“移动”，静止太久掉线 → 把 HC-SR501 延时电位器调到最小、跳线 H、远离热源 |
