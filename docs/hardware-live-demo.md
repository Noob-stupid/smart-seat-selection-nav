# ESP32 红外占座传感器 —— 真机演示与自测操作指南

> 目标：**读完这份，你自己就能把一台装有两个红外传感器的 ESP32 连到主系统，看到真实占用/释放，并能在答辩/汇报里演示。** 不需要懂复杂原理，按步骤照做即可。涉及原理的说明见 `docs/hardware-integration.md`。

---

## 0. 先搞清楚：你要演示哪种形态

| 形态 | 数据来源 | 适合场景 |
|---|---|---|
| **A 真机** | ESP32 每 5 秒上报红外读数 → 主系统判定 → 前端实时变色 | 答辩主推（"物联网感知"硬核点） |
| **B 模拟兜底** | 主系统自带"传感器模拟器"，后台按钮随机翻转座位 | 硬件临时故障时的保底演示 |

> 你之前问的"实体 ESP32 的 WiFi→HTTP 物理连通"，本质就一句话：**设备通过 WiFi 访问"主系统电脑的 IP:5800"的接口**。把下面第 3 步的服务器地址填对、设备和电脑在同一个 WiFi、电脑防火墙放行 5800，就通了。照着做即可，不用纠结概念。

---

## 1. 需要准备的材料

**硬件**
- 1 块 ESP32 开发板（如 ESP32 DevKit，USB 供电）
- 2 个红外避障传感器（默认用；若用 PIR 人体感应模块则在固件里改一下），或直接 2 个 PIR
- 杜邦线若干（传感器 OUT / VCC / GND 接到 ESP32）
- 1 根 USB 数据线（连电脑烧录 + 供电）
- 一台电脑（跑主系统） + 一台手机或另一台电脑（打开前端页面看效果）

**软件**
- VS Code + **PlatformIO** 插件（编译/烧录 ESP32），或命令行 `pip install platformio`
- Python 3.9+（跑主系统）
- 主系统源码目录：`D:\MAX_xiangmu`

## 2. 接线（按这张表插）

| ESP32 引脚 | 连到 |
|---|---|
| `GPIO23`（`IR_SENSOR_A_PIN` → `ir_front`） | 红外传感器 A 的 OUT |
| `GPIO27`（`IR_SENSOR_B_PIN` → `ir_back`） | 红外传感器 B 的 OUT |
| `3.3V` | 两个传感器 VCC |
| `GND` | 两个传感器 GND |

- 两个传感器**交叉放置**（座椅左前方 45° + 右后方 45°），人一坐下两束同时被遮 → 上报 `(1,1)`。
- 红外避障模块默认"检测到物体时输出 **LOW**"→ 固件里 `IR_ACTIVE_HIGH=false` 已配好；**若改用 PIR（检测到人体输出 HIGH）请改成 `true`**。
- 接好后给 ESP32 上电，板载 LED 亮/闪即正常。

## 3. 改固件连接参数（烧录前必改）

打开 `DEMO/src/main.cpp`，改顶部配置区：

```cpp
const char* WIFI_SSID     = "你的路由器名称";
const char* WIFI_PASSWORD = "你的路由器密码";
// 运行主系统那台电脑的局域网 IP + 端口 5800
const char* SERVER_URL    = "http://192.168.1.7:5800";
```

座位标识（两种选一种）：

```cpp
const bool IDENTIFY_BY_SEAT_LABEL = true;   // true=按标签(推荐)  false=按数字ID
const char* SEAT_LABEL = "A区-12";          // 必须与主系统里那个座位的 seat_label 完全一致
const int   FLOOR_ID   = 0;                 // 仅标签跨楼层重名时才需要填(>0)
const int   SEAT_ID    = 1;                 // IDENTIFY_BY_SEAT_LABEL=false 时填 seats.id
```

- **怎么找电脑局域网 IP**：电脑上跑 `ipconfig`，看"IPv4 地址"（形如 `192.168.x.x`）。
- **怎么找座位标签**：见第 5 步先建好座位，标签就是平面图上的那个编号。

---

## 4. 启动主系统（每次演示前这样做）

**① 关掉传感器模拟器**（很关键，否则随机数据会和真机互相覆盖）

编辑主系统目录下的 `.env`，加入一行：

```
SENSOR_SIMULATOR_AUTOSTART=False
```

> 或者主系统起来后，用管理员调 `POST /api/admin/simulator/stop`。二选一。

**② 让主系统监听所有网卡 + 端口 5800**

```bash
python app.py 0.0.0.0 5800
```

- 首次运行防火墙会弹窗，选"允许（专用 + 公用 网络）"，否则 ESP32 访问不到。
- 启动日志会打印类似 `局域网访问 http://192.168.x.x:5800`，**记下这个 IP 填进固件 `SERVER_URL`**。

> 数据库说明：主系统默认尝试连 MySQL；连不上会自动回退 SQLite，演示照跑。Redis 不装也会自动退化为单进程模式，不影响演示。

## 5. 先在主系统里建好"要绑定的座位"

1. 用管理员账号登录 → 管理端 → 建筑/楼层 → 创建一栋楼和一个楼层。
2. 在楼层里**放一个座位**（或直接在座位管理里建一个座位），保存。
3. 记下它的**座位标签 `seat_label`**（就是平面图上显示的编号，如 `A区-12`）。
4. 把这个标签**原样**填进 `main.cpp` 的 `SEAT_LABEL`（见第 3 步）。

## 6. 烧录固件并看串口

```bash
cd DEMO
pio run -t upload        # 第一次会自动下载工具链，耐心等
pio device monitor       # 波特率 115200
```

串口应看到：

```
[WiFi] 已连接，IP = 192.168.x.x
[HTTP] POST http://192.168.x.x:5800/api/sensor/report -> {"seat_label":"A区-12","ir_front":0,"ir_back":0}
[HTTP] 上报成功 HTTP 200（ir=(0,0)）
```

> 常见：`上报失败 HTTP 404` → 座位标签填错；`HTTP -1 / 连接超时` → 主系统没 `0.0.0.0` 启动 / 不同 WiFi / 防火墙没放行 5800（重点核对 `SERVER_URL` 的 IP 和端口）。

## 7. 前端看真实占用 / 释放

1. 手机或另一台电脑浏览器打开 `http://<主系统IP>:5800` → 登录**用户端** → 进入「**座位图**」页。
2. 让一位同学坐到你绑定的那个座位：`(1,1)` → **≤5 秒**座位图变**红**（占用）。
3. 同学离开：连续两次"无人"上报 → 约 **10 秒**变回**绿**（释放）。
4. 锁定、预约、导航照常可用；座位图**无需刷新**（WebSocket 实时推送）。

---

## 8. 演示脚本（答辩 / 汇报照着念）

1. 打开「座位图」页，展示当前座位全是绿色（空闲）。
2. 请一位同学坐下 → 讲："这是**真实传感器**上报，前端 **5 秒内自动变红**，无需刷新页面。"
3. 同学离开 → 讲："连续两次'无人'上报，约 **10 秒自动释放**变回绿色。"
4. （加分项）占用满 m 分钟后，在座位弹窗点「锁定」，讲解 **m/n 动态防抢座**；再演示**室内导航**导航到该座位。
5. 收尾强调："整条判定/锁定/导航链路都在主系统完成，设备端只做持续扫描+上报，软硬件解耦。"——这正好呼应"物联网感知"的项目定位。

## 9. 常见问题速查

| 现象 | 排查 |
|---|---|
| 串口 `上报失败 HTTP 404` | `SEAT_LABEL` 与该座位 `seat_label` 不一致（或座位不存在） |
| `HTTP 400`，提示"匹配到多个座位" | 同名标签跨楼层，填 `FLOOR_ID` 消歧 |
| `HTTP -1` / 连接超时 | 主系统是否 `0.0.0.0` 启动；ESP32 与电脑同一 WiFi；防火墙放行 5800 |
| 人坐下座位不变红 | 电平反了：`IR_ACTIVE_HIGH` 改成 `true` 试试；看接线与串口 `ir=(1,1)` 是否出现 |
| 座位频繁闪红/绿 | 传感器模拟器还在跑，先停（第 4 步） |
| 座位显示**异常**（灰/叹号） | 设备连续停止上报超过 `SEAT_OFFLINE_HOURS`；恢复供电会自动转回正常 |

## 10. 附录

**两种座位标识怎么选**
- 按**标签**（推荐，人 readable）：`IDENTIFY_BY_SEAT_LABEL=true`，填 `SEAT_LABEL`。换座位只需改标签。
- 按**数字 ID**：`IDENTIFY_BY_SEAT_LABEL=false`，填 `SEAT_ID`（数据库 `seats.id`）。

**红外避障 vs PIR**
- 红外避障：检测到物体输出 LOW → 适合"座椅是否被占"。
- PIR 人体感应：检测到人体输出 HIGH → 适合"是否有人"，但对静止久坐的人可能不灵敏。
- 默认按红外避障配置（`IR_ACTIVE_HIGH=false`），换 PIR 记得改 `true`。

**没有真机时怎么演示（兜底 B）**
- 启动主系统后，管理员调用 `POST /api/admin/simulator/start` 开启模拟器；或保持 `SENSOR_SIMULATOR_AUTOSTART=True`。
- 再用 `POST /api/admin/simulator/occupy`（带 `seat_id` + `occupied`）手动把某个座位翻成占用/空闲，前端同样会实时变色，也可演示锁定/导航。
